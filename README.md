# 🔥 Fenix CRM — Sistema Central de Ventas, Supervisores y Pagos Adicionales

Plataforma web todo-en-uno optimizada para reemplazar Google Sheets + Tally + Apps Script:
- **Admin Principal (`/?vista=admin`)**: Control total de Hojas de Ventas, Ventas del Día, Pagos Adicionales, Accesos por Correo y Sincronización.
- **Ventas Fenix (`/ventas-fenix`)**: Vista operativa dedicada con edición en línea de ventas existentes, Ventas del Día y Pagos Adicionales (sin selector de vistas ni creación de hojas).
- **Formulario Independiente (`/formulario`)**: Captura inteligente de fichas para ejecutivos (con agrupación por compañía y lectura en vivo de números titulares y adicionales).
- **Vistas Espejo por Supervisor (`/?vista=supervisor&id=...`) y Móviles (`/?vista=moviles`)**: Protegidas mediante lista blanca de correos electrónicos.
- **API REST para n8n y Telegram (`/api/n8n/*`)**.
